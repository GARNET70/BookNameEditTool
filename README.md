# BookNameEditTool

書籍フォルダの名前を、SQLite に登録された書誌情報を使って整理する Windows デスクトップアプリケーションです。フォルダ名からタイトルを検索し、候補の書誌情報を確認・編集して、フォルダのリネームやデータベースの更新を行えます。

## 主な機能

- 指定した作業フォルダ直下のフォルダを一覧表示
- フォルダ名を使って、SQLite の日本語・英語タイトルを部分一致検索
- 検索候補から書誌情報を読み込み、タイトル・作者・巻数・状態・memo を編集
- `[作者] タイトル(日本語) 第xx巻` の形式でフォルダ名を作成
- Windows で使用できない文字などを取り除いて、対象フォルダをリネーム
- 選択した候補の書誌情報を SQLite に登録
- 作業が完了したフォルダを画面上の一覧から外して次のフォルダへ進む

## 使い方

1. [設定ファイル](BookNameEditTool/json/paths.json)に作業フォルダとデータベースのパスを設定します。
2. アプリを起動し、「取得」を押して作業フォルダ内の一覧を読み込みます。
3. 対象フォルダを選択して「検索」を押します。フォルダ名に `_v` と巻数が含まれる場合、巻数は巻数欄にも反映されます。
4. 「更新候補」から候補を選び、「OK」で書誌情報を入力欄に読み込みます。必要に応じて内容を編集します。
5. 「フォルダ名作成」で名前を作成し、必要であれば確認・編集したうえで「リネーム」を押します。
6. 「DB登録」で選択中の候補を入力内容で更新します。
7. 「完了」を押すと、対象フォルダは画面上の一覧から外れます。実フォルダは削除されません。

## 設定

`BookNameEditTool/json/paths.json` を次の形式で設定してください。

```json
{
  "work": {
    "path": "D:\\Books\\ToSort"
  },
  "DB": {
    "path": "db\\booklist.db"
  }
}
```

- `work.path`: 処理対象フォルダが入っているフォルダのパスです。作業フォルダにはアプリの読み書き権限が必要です。
- `DB.path`: SQLite データベースのパスです。相対パスはアプリの実行フォルダを基準に解決されます。検索だけなら読み取り可能であれば使えますが、「DB登録」には書き込み権限が必要です。
- `paths.json` はビルド時にアプリの出力先の `json` フォルダへコピーされます。配布・実行環境では、出力先の `json/paths.json` も確認してください。

データベースには `booklist` テーブルが必要です。アプリは `Title_JP`、`Title_EN`、`author`、`Vol`、`status`、`memo` を検索・表示し、更新時にはこれらに加えて `updatetime` も更新します。対象行は SQLite の `rowid` で特定します。

## 動作環境・ビルド

- Windows
- .NET 8 SDK
- SQLite データベース（`Microsoft.Data.Sqlite` を使用）

Visual Studio で `BookNameEditTool.sln` を開いてビルドするか、リポジトリのルートで次を実行してください。

```powershell
dotnet build .\BookNameEditTool.sln
```

アプリは Windows Forms の GUI アプリケーションとして起動します。
